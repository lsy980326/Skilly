구성요소는 어떻게 나뉘나요?

Web·API·Mobile·Bot처럼 서비스 안의 역할을 나눈 단위입니다. 작업과 연결 설정에 지정된 정보를 사용하며, 제목이나 폴더 이름으로 추정하지 않습니다. 한 항목이 여러 구성요소에 연결될 수 있습니다.

기능은 연결 작업, 계획은 현재 버전의 항목 지정, 스킬은 설치 연결 설정, 저장 문제는 보관된 요청이나 같은 범위의 작업을 따릅니다. 연결 정보 없음은 해당 근거가 없다는 뜻입니다. 이 순서는 실제 서버 호출 순서가 아닙니다.
